# 🩻 Chest X-Ray Classification Using Deep Learning

A deep learning project that classifies chest X-ray images into **Normal** and **Abnormal** categories using a Convolutional Neural Network (CNN). The project covers image preprocessing, model training, evaluation, and deployment through an interactive Streamlit web application.

## 📌 Project Overview

This project aims to demonstrate how deep learning and computer vision techniques can be applied to medical image classification.

The model processes chest X-ray images and predicts whether an image belongs to the Normal or Abnormal class. A Streamlit application provides a simple interface where users can upload an image and view the model's prediction.

> **Disclaimer:** This project is intended for educational purposes only. It is not a clinically validated diagnostic system and must not be used as a substitute for professional medical advice or diagnosis.

## ✨ Key Features

- **Image Preprocessing:** Converts images to grayscale, resizes them, and normalizes pixel values.
- **CNN Model:** Uses a Convolutional Neural Network for image classification.
- **Model Training:** Applies Batch Normalization, Dropout, and training callbacks.
- **Model Evaluation:** Evaluates performance using Accuracy, Precision, and Recall.
- **Interactive Web App:** Allows users to upload chest X-ray images and view predictions.
- **Deep Learning Deployment:** Integrates a trained TensorFlow/Keras model with Streamlit.

## 🧠 Model Development

The model development workflow includes the following stages:

1. **Dataset Preparation:** Loads and organizes chest X-ray images.
2. **Image Preprocessing:** Converts images to grayscale, resizes them to `128 × 128` pixels, and normalizes pixel values to the `[0, 1]` range.
3. **Model Building:** Uses a CNN architecture with convolutional layers, pooling, Batch Normalization, and Dropout.
4. **Model Training:** Uses training callbacks such as Early Stopping and ReduceLROnPlateau.
5. **Model Evaluation:** Measures model performance using Accuracy, Precision, and Recall.
6. **Model Saving:** Saves the trained model as `chest_xray_model.h5`.
7. **Deployment:** Loads the saved model into a Streamlit application for image classification.

## 🚀 Run the Application

Ensure that `APP.py` and `chest_xray_model.h5` are located in the same directory.

Run the following command:

```bash
streamlit run APP.py
```

A local URL will appear in the terminal. Open it in your browser to access the application.

### How to Use

1. Open the Streamlit application.
2. Upload a chest X-ray image in PNG, JPG, or JPEG format.
3. Click the analysis button.
4. View the predicted class: **Normal** or **Abnormal**.
